# Plan critique, Sprint 0, round 1: a summary and what was done

A read-only critic reviewed the first draft of both plans on 23 November
2026 and returned nineteen concerns with the verdict `proceed-with-caveats`.
This file is a summary of that review, written by the planner, with the
response to each concern. The plans and intents were revised accordingly and
reviewed again; the second review is [critique.md](critique.md), which is
the critic's own text.

| concern | failure mode | what the critic found | response |
|---|---|---|---|
| C-001 | intent-drift | The review that keeps the repository in its own terms was too loosely specified: it covered only the head of `dev` and its messages, named no method, and was recorded once, after the pushes it was meant to guard. | Fixed in plan. The review is task T-013, with its scope (every file each unpushed commit adds or changes, every message, the fonts' name tables, the text of a pull request, tag or release), its method (a list kept outside the repository and one reading of new prose), its timing (before every push, with an entry giving the range covered), and what follows a finding. |
| C-002 | plan-test-mismatch | INT-0001 criterion 5 was claimed as covered but had no task and no EARS clause. | Fixed in plan. T-013 owns it, and four named reviews trace to its clauses. |

The fonts go in as built; INT-0002's Consequences record the embedding field; the README says `fonts/OFL.txt` states the fonts' terms; backlog task T-101 takes in a later build that sets the fields. Setting them is work in another project. |
